## Om Novatrix

Novatrix AB är det fiktiva företag vi bygger åt genom hela kursen.
Novatrix vill flytta sin webbplats till AWS. Varje vecka bygger vi vidare på samma miljö, tills den blir en WordPress-sajt med nätverk, databas, lagring, skalbarhet och monitorering.
